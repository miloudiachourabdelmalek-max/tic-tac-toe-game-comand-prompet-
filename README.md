# Tic-Tac-Toe 🎮

A simple **console-based Tic-Tac-Toe game written in C++**, where you play against the computer.

## Features

* Player vs Computer
* Choose **X or O**
* Supports **QWERTY and AZERTY** keyboard layouts
* Random computer moves
* Win and draw detection
* Input validation

## Technologies

* C++
* `iostream`
* `vector`
* `map`
* `ctime`

## Run

```bash
g++ main.cpp -o tic-tac-toe
./tic-tac-toe
```
